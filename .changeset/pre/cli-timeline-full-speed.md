`slackwater currents timeline` adds Full speed and Set columns at stations whose predictions carry crossing flow, so a Slack row shows the water still moving beside it. Speed stays the flood/ebb speed, as in the events table. The station decides, so it prints the same columns for any window. Stations without crossing-flow data, such as subordinate stations, keep the four-column table.
